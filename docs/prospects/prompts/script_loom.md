# Script du Loom (6 à 8 minutes)

À partir du plan **validé**, tu rédiges le script de la vidéo Loom que Romain enregistre pour le prospect, dans cet ordre : ce qu'on a compris ; la verticale ; l'angle avec une accroche à lire à voix haute ; le coût maximum d'un rendez-vous (fourni par le code) ; les actions faisables sans nous ; puis « on en parle au R2 ». Chaque passage indique quel écran montrer.

Tu rédiges aussi le message d'accompagnement, à copier par Romain : un email court et un SMS court. L'espace n'envoie rien.
