Votre calendrier n'est pas un agenda : c'est **le point d'arrivée de tout le tunnel**. Tout ce qu'on a construit en amont sert à remplir cet écran.

@[Configurer votre calendrier de rendez-vous](https://www.tella.tv/video/configurer-votre-calendrier-de-rendez-vous-ciee)

## Ce que couvre ce cours

La configuration complète :

- vos **disponibilités réelles** ;
- la **durée des créneaux** ;
- le **délai minimum** avant réservation ;
- le **temps tampon** entre deux rendez-vous ;
- la **synchronisation bidirectionnelle** avec votre agenda personnel.
