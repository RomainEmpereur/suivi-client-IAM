Ce guide couvre tout ce que nous avons besoin de voir configuré côté Meta (Facebook) avant de pouvoir diffuser vos publicités et gérer vos comptes. Suivez-le de haut en bas.

L'ensemble prend **20 à 30 minutes**. Faites-le sur un **ordinateur** plutôt que sur votre téléphone : certains écrans sont difficiles à atteindre sur mobile.

Vous n'avez pas besoin d'une entreprise entièrement créée pour faire tout ça. Chaque fois qu'une étape demande quelque chose que vous n'avez pas encore (un nom d'entreprise, un nom de domaine…), une note « *Vous ne l'avez pas encore ?* » vous dit quoi faire.

> La version PDF de ce guide, avec une capture d'écran pour chaque étape, est accessible avec le bouton **Version vidéo / PDF** en haut de cette page.

**Avant de commencer, préparez :**

- Un compte Facebook personnel (nous en créons un à l'étape 1 si vous n'en avez pas).
- Le nom, l'adresse et le site web de votre entreprise. *Pas encore de nom d'entreprise ? Utilisez votre propre nom pour l'instant. Ce nom n'est pas public et vous pouvez le changer à tout moment.*
- Une carte bancaire (débit ou crédit) pour le compte publicitaire.

> **Astuce** — Meta appelle votre Business Manager « portefeuille business » (*Business Portfolio*) sur certains écrans et « Business Manager » sur d'autres. C'est la même chose.

---

## Étape 1 — Créez votre Meta Business Manager

Votre Business Manager est la base qui contient votre Page, votre compte publicitaire, votre Instagram et vos données. Tout le reste vit à l'intérieur.

1. Rendez-vous sur **[business.facebook.com](https://business.facebook.com)** et cliquez sur **« Créer un compte »**.
2. Si vous n'avez pas encore de compte Facebook personnel, créez-en un d'abord, avec votre vrai nom et n'importe quelle adresse email à laquelle vous avez accès (une adresse personnelle convient). Vous ne l'utilisez que pour vous connecter : ce n'est pas votre Page professionnelle.
3. Connectez-vous avec ce compte Facebook lorsque cela vous est demandé.
4. Vous arrivez dans **Meta Business Suite** : c'est votre tableau de bord.
5. Pour atteindre les paramètres utilisés dans la suite de ce guide, cliquez sur **« Tous les outils »**, puis ouvrez **Paramètres** (l'icône en forme d'engrenage).

---

## Étape 2 — Créez votre Page Facebook

Votre Page est le visage public de votre entreprise sur Facebook. Les publicités sont diffusées depuis celle-ci.

1. Dans **Paramètres**, ouvrez **Comptes → Pages**.
2. Cliquez sur **« Ajouter »**, puis sur **« Créer une nouvelle Page Facebook »**.
3. Saisissez le nom de votre Page (le nom de votre entreprise), choisissez une catégorie qui correspond à votre activité et ajoutez une courte biographie si vous le souhaitez.
   *Pas encore de nom d'entreprise ? Utilisez votre propre nom comme nom de Page (la campagne principale sera diffusée depuis une page à votre nom).*
4. Vérifiez les informations et confirmez. Votre Page est créée et ajoutée à votre Business Manager.

> **Astuce** — Vous avez déjà une Page ? Choisissez plutôt **« Ajouter une Page Facebook existante »**, saisissez le nom ou l'adresse de la Page et suivez les instructions.

---

## Étape 3 — Créez votre compte publicitaire

C'est le compte sur lequel vos publicités sont facturées et depuis lequel elles sont diffusées.

1. Dans **Paramètres**, ouvrez **Comptes → Comptes publicitaires**, puis cliquez sur **« Ajouter » → « Créer un compte publicitaire »**.
2. Donnez-lui un nom, définissez votre **fuseau horaire** et choisissez votre **devise**. **Choisissez-les avec attention : ils ne pourront plus être modifiés.**
   *Pas encore de nom d'entreprise ? Nommez le compte publicitaire à votre nom pour l'instant. Ce nom n'est pas public et vous pourrez le changer plus tard. Seuls le fuseau horaire et la devise sont définitifs.*
3. Lorsqu'on vous demande à qui appartient le compte publicitaire, choisissez **« Mon entreprise »**.

---

## Étape 4 — Ajoutez votre compte Instagram

Connecter Instagram nous permet de diffuser des publicités à la fois sur Facebook et sur Instagram.

1. Dans **Paramètres**, ouvrez **Comptes → Comptes Instagram** et cliquez sur **« Ajouter »**.
2. Connectez-vous au compte Instagram que vous souhaitez relier.

Seul un compte Instagram **professionnel** (Business ou Créateur) peut être ajouté. Un compte personnel est automatiquement basculé en compte professionnel.
*Pas de compte Instagram, ou vous ne voulez pas utiliser votre compte personnel ? Créez d'abord un nouveau compte professionnel, idéalement à votre nom, puis connectez-le ici.*

---

## Étape 5 — Renseignez les informations de votre entreprise

Remplir les informations de votre entreprise garde votre compte en règle et est nécessaire pour la vérification.

1. Dans **Paramètres**, ouvrez **Infos sur l'entreprise**, puis cliquez sur **« Modifier »**.
2. Ajoutez le nom de votre entreprise, sa photo et sa Page principale.
3. Vérifiez que votre **raison sociale**, votre **adresse**, votre **téléphone** et votre **site web** sont corrects.

*Vous n'avez pas encore ces informations ? Vous pouvez laisser cette partie de côté et continuer. C'est ce qui débloque la vérification, laquelle augmente vos limites de dépenses et évite que votre compte soit signalé : revenez la remplir dès que le nom et l'adresse de votre entreprise sont réglés, ou dès que votre société est immatriculée.*

---

## Étapes 6 et 7 — Créez votre ensemble de données et votre pixel

Le pixel est l'élément de suivi qui nous indique ce que font les personnes après avoir cliqué sur une publicité. Dans l'interface actuelle de Meta, le pixel vit à l'intérieur d'un **ensemble de données** (*dataset*) : créer votre ensemble de données crée donc votre pixel en même temps.

1. Dans **Paramètres**, ouvrez **Sources de données → Ensembles de données et pixels**.
2. Cliquez sur **« Ajouter »** et saisissez un nom (le nom de votre entreprise fonctionne bien).
   *Pas encore de nom d'entreprise ? Nommez l'ensemble de données à votre nom pour l'instant : ce nom n'est pas public et vous pourrez le changer.*
3. Laissez le menu « Sélectionnez les catégories applicables » **vide** : ne choisissez aucune catégorie.
4. Cliquez sur **« Créer »**. C'est votre pixel.

Après la création, Meta peut vous proposer de déployer ou d'intégrer le pixel sur votre site. **Ignorez cette étape** : ne l'installez nulle part. Nous nous chargeons de l'installation une fois que tout est connecté.

---

## Étapes 8 et 9 — Vérifiez votre compte publicitaire et votre numéro de téléphone

La vérification débloque des limites de dépenses plus élevées et évite que votre compte soit signalé. Les deux se trouvent sur le même écran.

1. Dans **Paramètres**, faites défiler vers le bas et ouvrez **« Autorisations et vérifications »**.
2. Utilisez **« Vérifiez-vous ou vérifiez une organisation »** pour vérifier le compte publicitaire.
   *Pas d'entreprise immatriculée ? Choisissez « Se vérifier soi-même » et vérifiez-vous en tant que particulier. Vous pourrez vérifier l'organisation plus tard.*
3. Utilisez **« Vérification du numéro de téléphone »** pour vérifier un numéro associé au compte publicitaire.

---

## Étape 10 — Ajoutez un moyen de paiement à votre compte publicitaire

Les publicités ne peuvent pas être diffusées sans carte enregistrée sur le compte publicitaire.

1. Dans **Paramètres**, ouvrez **Facturation et paiements → Moyens de paiement**.
2. Sélectionnez dans le menu déroulant le compte publicitaire créé à l'étape 3.
3. Cliquez sur **« Ajouter un moyen de paiement »** et choisissez **Carte de débit ou de crédit**.
4. Saisissez les informations de la carte et enregistrez.
5. Vérifiez que la carte est bien rattachée et contrôlez votre limite de dépenses sur l'écran de facturation du compte.

---

## Étape 11 — Donnez-nous accès

C'est ainsi que vous nous permettez de travailler dans votre Business Manager **sans jamais partager vos identifiants**.

1. Dans **Paramètres**, ouvrez **Utilisateurs → Personnes**.
2. Cliquez sur **« Inviter des personnes »** et renseignez l'adresse email que nous vous avons communiquée.
3. Accordez l'**accès total** : sous « Accès total », activez **Gérer**.
4. Sélectionnez les éléments à partager. **L'idéal est de tout partager.**

## Étape 12 — Attribuez le contrôle total sur chaque ressource

Activez le **contrôle total** sur chaque ressource, afin que nous puissions tout diffuser et optimiser de bout en bout. Sur l'écran « Attribuer des ressources et des autorisations », parcourez chaque type de ressource dans la colonne de gauche :

| Ressource | À faire |
|---|---|
| **Pages Facebook** | sélectionnez votre Page, puis activez **Contrôle total** |
| **Comptes publicitaires** | sélectionnez votre compte publicitaire, puis activez **Contrôle total** |
| **Comptes Instagram** | sélectionnez votre compte Instagram, puis activez **Contrôle total** (Tout) |
| **Pixels** | votre pixel se trouve désormais sous Ensembles de données ; si cet onglet est vide, attribuez-le depuis l'onglet Ensembles de données |
| **Ensembles de données** | sélectionnez votre ensemble de données (votre pixel), puis activez **Contrôle total** |
| **Domaines** | sélectionnez votre domaine et attribuez-le |

*Pas encore de nom de domaine ? Passez cette étape pour l'instant. Quand vous l'aurez, ajoutez-le à votre Business Manager et attribuez-le-nous depuis ce même écran.*

Cliquez ensuite sur **« Attribuer les ressources »** pour terminer.

- [ ] Page Facebook créée
- [ ] Compte publicitaire créé avec nom, fuseau horaire et devise définis
- [ ] Compte Instagram connecté
- [ ] Informations de l'entreprise renseignées
- [ ] Ensemble de données et pixel créés
- [ ] Compte publicitaire et numéro de téléphone vérifiés
- [ ] Moyen de paiement ajouté au compte publicitaire
- [ ] Contrôle total attribué sur la Page, le compte publicitaire, Instagram, le pixel, l'ensemble de données et le domaine

## Où trouver vos identifiants

Nous pouvons vous demander ces identifiants pour finir le branchement. Envoyez-les dans **Feedback** :

| Identifiant | Où le trouver |
|---|---|
| **ID du Business Manager** | Paramètres → Infos sur l'entreprise, sous le nom du portefeuille (« ID du portefeuille business ») |
| **ID de la Page Facebook** | Paramètres → Comptes → Pages → votre Page, sous son nom |
| **ID du compte publicitaire** | Paramètres → Comptes → Comptes publicitaires → votre compte, sous son nom |
| **ID du pixel** | Paramètres → Sources de données → Ensembles de données et pixels → votre ensemble, sous son nom |
