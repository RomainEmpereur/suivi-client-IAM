# 0030 — Liste de tâches de l'agence

Date : 2026-11-14

## Contexte
Romain veut suivre, côté agence, ce qu'il doit faire pour chaque client : une tâche, une échéance, un court descriptif.

## Décision
- Table `agency_tasks` (migration 0024) : client (ou aucun = tâche de l'agence), titre, descriptif, échéance (date, facultative), statut à faire / fait, date de réalisation. Vue agence uniquement : aucune route client, jamais visible d'un client.
- Écran « Tâches » dans le menu agence : ajout rapide, filtre par client ou « Agence », groupes En retard / Aujourd'hui / À venir / Sans échéance, case à cocher pour « fait » (réversible), modification et suppression. Les tâches faites restent consultables.
- Le menu affiche le nombre de tâches en retard ou à faire aujourd'hui (heure de Paris). La fiche client montre ses tâches ouvertes et renvoie à la liste filtrée.
- Création, modification et suppression sont journalisées. Aucun envoi (email, notification) : la liste sert de mémoire, pas de relance.
